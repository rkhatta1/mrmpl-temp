# MRMPL Catalog

The product catalog and the language administrators use to prepare catalog imports.

## Language

**Product**:
A catalog item identified by a part code.

**Part code**:
The unique business identifier of a product.
_Avoid_: Photo code when referring to product identity.

**Category**:
A top-level grouping of products.

**Subcategory**:
A grouping of products within one category.

**Photo code**:
An administrator-supplied catalog identifier for a specific image file, also used as its filename. Multiple products may reference the same photo code; the code keeps the same image identity across imports.
_Avoid_: Part code when referring to image identity.

**Catalog import**:
A submission of new products and their category/subcategory assignments using the official workbook, accompanied by any referenced image files.

**Import template**:
The official workbook defining the fields expected for a catalog import.
